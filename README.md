# UltimateArmoury: Tools And Weapons

The materials and equipment mod of the **Ultimate** family, for NeoForge.

A three-tier progression, **Mushashite → JoanFoite → Nadienite**, with ores, armor sets with set bonuses and a 3D helmet per tier, tools, weapons, compressed blocks, and Ex Deorum and AllTheModium integration.

Standalone: it needs none of the other Ultimate mods.

## Requirements

* NeoForge for Minecraft 1.21.1
* GeckoLib
* Patchouli

Optional: JEI, Jade, Ex Deorum, AllTheModium.

## Branches

* `Neo/1.21.1` — Minecraft 1.21.1
* `Neo/26.1.2` — Minecraft 26.1.2
